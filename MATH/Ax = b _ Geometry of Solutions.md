FULL SOLUTIONS (Q1–Q30)
------------------------------------------------------------
Q1. Condition for existence of a solution
------------------------------------------------------------
Ax = b has a solution ⇔ rank(A) = rank([A|b]).

Option a.

Answer: a


------------------------------------------------------------
Q2. When does no solution occur?
------------------------------------------------------------
A system has NO solution when the augmented matrix has a row like:
    [0 0 … 0 | non-zero]
which is inconsistent.

Option b.

Answer: b


------------------------------------------------------------
Q3. Hyperplane definition
------------------------------------------------------------
A hyperplane is the set of solutions to ONE linear equation:
    a₁x₁ + … + aₙxₙ = c.

Option c.

Answer: c


------------------------------------------------------------
Q4. Unique solution condition
------------------------------------------------------------
For an n-variable system, unique solution requires:
    rank(A) = n
(no free variables).

Answer: a


------------------------------------------------------------
Q5. If A is invertible
------------------------------------------------------------
Then Ax = b has exactly ONE solution:
    x = A⁻¹b.

Answer: b


------------------------------------------------------------
Q6. Which augmented matrix indicates no solution?
------------------------------------------------------------
Check each:

c)
[1 1 | 1]
[0 0 | 4]  ← impossible row

This is inconsistent.

Answer: c


------------------------------------------------------------
Q7. Infinite solutions condition
------------------------------------------------------------
Infinite solutions when:
    rank(A) = rank([A|b]) < number of unknowns

Option a.

Answer: a


------------------------------------------------------------
Q8. Meaning of Ax = b in R²
------------------------------------------------------------
Each equation is a line. System → line intersection or parallel → a line or none.

Option b.

Answer: b

Free variable: let z = t ⇒ y = 2 – t.

Solution set:
x = 1, y = 2 – t, z = t ⇒ infinite solutions.

Answer: c

Q27. Solve:
x + y + z = 2  
2x + 2y + 2z = 4  
y + z = 1  
------------------------------------------------------------
Second eq is 2×first.  
Compare eq1 and eq3:

(x + y + z = 2) minus (y + z = 1) ⇒ x = 1.

Eq3: y + z = 1 ⇒ infinitely many (free param).

Solution set:
x = 1  
y = 1 – t  
z = t

Infinite solutions.

Answer: c


------------------------------------------------------------
Q28. For:

------------------------------------------------------------
Check Row3 – (Row1 + Row2):

Row1 + Row2 = [1 1 5]  
Row3 = [1 1 5]  

b also satisfies: 7 = 3 + 4.

No inconsistencies.

Answer: a
