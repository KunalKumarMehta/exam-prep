**Web Development II**

## **Topics**

1. **JavaScript Asynchronous Programming Fundamentals**
   - Synchronous vs asynchronous execution

   - Real-world use cases for async operations

   - Event loop (conceptual understanding)

2. **Asynchronous Callbacks**
   - Callback function patterns

   - Error-first callback convention

   - Handling async results using callbacks

   - Common callback pitfalls

3. **Timers and Delayed Execution**
   - Using `setTimeout` for delayed operations

   - Time-based task scheduling

   - Validating delay inputs

   - Understanding non-blocking timers

4. **Promises – Core Concepts**
   - Creating promises

   - Promise states (pending, fulfilled, rejected)

   - Resolving and rejecting promises

   - Handling success and failure with `.then()` and `.catch()`

5. **Promise Chaining**
   - Sequential async operations using `.then()`

   - Passing data between chained promises

   - Error propagation in promise chains

   - Real-world workflows using chaining

6. **Async / Await**
   - Writing asynchronous code using `async` and `await`

   - Sequential async logic using `await`

   - Error handling with `try/catch`

   - Comparing async/await with promise chaining

7. **Serial Execution of Promises**
   - Executing async tasks one after another

   - Building controlled execution flows

   - Collecting results from sequential operations

   - Use cases where serial execution is required

8. **Parallel Execution of Promises**
   - Executing independent async tasks in parallel

   - Performance benefits of parallel execution

   - Preserving result order

   - Handling failures in parallel tasks

9. **Promise Combinators**
   - `Promise.all`
     - Running multiple promises concurrently

     - Failure behavior and result ordering

   - `Promise.race`
     - Identifying the fastest promise

     - Handling early resolution or rejection

   - `Promise.allSettled`
     - Handling partial successes and failures

     - Reporting per-task results

   - `Promise.any`
     - Resolving with the first successful promise

     - Handling aggregate failures
